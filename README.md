# Ryōiki
Portafolio fotográfico inmersivo. Móvil primero (doble toque = favorita, riel lateral, deslizar baraja) y adaptado a computadora (dos columnas, cursor, inclinación 3D, teclado ↑↓ F M).
Fotos del bucket público `dominio` de Supabase.
`npm install && npm run dev` · Deploy: GitHub → Vercel (sin configuración).
